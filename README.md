#  Flipa

**Flipa** es un micro-framework full-stack ligero, construido desde cero con **PHP 8.3**. 

Diseñado con un enfoque 100% educativo, su objetivo es desmitificar el funcionamiento interno de los grandes frameworks modernos (como Laravel o Symfony). Flipa prioriza la comprensión profunda de los patrones de diseño, el Clean Code y los estándares PSR, evitando la sobre-ingeniería y manteniendo una base de código limpia y extensible.

## Stack Tecnológico

*   **Core:** PHP 8.3 (Tipado estricto, Constructor Property Promotion, Readonly classes).
*   **Gestión de dependencias:** Composer (Autoloading PSR-4).
*   **Entorno:** vlucas/phpdotenv (Variables de entorno).
*   **Manejo de errores:** filp/whoops (Pantallas de error detalladas en desarrollo).
*   **Testing:** PHPUnit / Pest.
